# Pendientes — cosas que esperan un dato o una decisión

Acá vive todo lo que **no se puede terminar hasta que llegue información de afuera**: una
medida de huincha, un papel del camión, una decisión de bodega.

**Ninguno bloquea nada.** El sistema funciona completo sin todos ellos. Cada uno enciende
algo que ya está construido y desplegado, esperando el dato.

Se guardó acá el **12-08-2026**, por pedido del dueño: *«guardá todo lo pendiente en una
carpeta y lo vamos viendo más adelante, dividilo por tema para que no se mezclen»*.

## Cómo se trabaja acá

Regla del proyecto, y es la razón por la que existe esta carpeta: **no se inventan números.**
Un dato que falta se queda en `null`, con la falta escrita en las notas del sembrador y a la
vista en la pantalla. Un número puesto «para que funcione» es peor que la ausencia, porque la
ausencia se nota y el inventado se cotiza.

Cuando llegue un dato: se completa, se corre la suite y se saca de acá.
